## 1. 系统概述

**定时任务报表系统**是一个企业级的自动化报表生成与分发平台，支持以下核心功能：

| 功能模块 | 说明 |
|---------|------|
| **SQL 任务** | 多数据源 SQL 查询，输出 CSV / Excel / Word / PPT / TXT 等格式 |
| **网页爬取** | 静态页面（Jsoup）和动态页面（Selenium）数据采集 |
| **任务调度** | 基于 Quartz 的 CRON 定时调度和一次性任务 |
| **报表模板** | Excel / Word / PPT 模板，通过 `${fieldName}` 占位符自动填充 |
| **图表生成** | 支持柱状图、折线图、饼图、面积图、散点图等 |
| **通知分发** | 邮件、企业微信、钉钉、飞书、Slack、Webhook |
| **AI 助手** | 自然语言生成 SQL、智能通知优化、数据分析对话 |
| **存储管理** | 本地存储、阿里云 OSS、AWS S3、WebDAV |
| **权限控制** | 基于角色的访问控制（RBAC），支持用户/角色/权限管理 |

### 技术栈

- **后端**：Java 17 + Spring Boot 3 + MyBatis-Plus + Quartz
- **前端**：Vue 3 + TypeScript + Element Plus + Vite
- **数据库**：MySQL 8.0

## 4. SQL 管理

SQL 管理模块用于配置数据查询语句，是报表生成的核心。

![SQL 管理列表](images/03-task-sql.png)

### 4.1 列表页面

- **SQL 配置** Tab：展示所有 SQL 配置项
- **SQL 分组** Tab：管理 SQL 的分组分类
- 支持按 SQL 名称、SQL 编码、分组进行搜索过滤
- 表格展示 SQL 名称、编码、分组、数据源、模板、输出格式、状态等信息
- 操作列支持 **编辑** 和 **删除**

### 4.2 新建/编辑 SQL

点击 **新增 SQL** 按钮或列表中的 **编辑** 链接，打开 SQL 配置对话框。

![SQL 新建对话框](images/03a-task-sql-create.png)

**配置项说明：**

| 字段 | 说明 |
|------|------|
| **SQL 名称** | SQL 配置的显示名称（必填） |
| **SQL 编码** | 唯一标识编码，用于程序引用（必填） |
| **数据源** | 选择该 SQL 要查询的数据库（必填） |
| **SQL 内容** | 查询语句，支持 `${参数名}` 占位符引用自定义参数（必填） |
| **默认时间** | 快捷填充时间范围（如：今天、昨天、本周、本月等） |
| **自定义参数** | JSON 格式，key 对应 SQL 中的 `${xxx}` 占位符 |
| **报表模板** | 关联 Excel/PPT/Word 模板文件，用于格式化输出 |
| **输出格式** | 支持 CSV、Excel、Word、PPT、TXT、INLINE |
| **Excel 合并组** | 同组的多个 SQL 合并到同一 Excel 文件的不同 Sheet |
| **Sheet 名称** | 自定义 Sheet 名称，默认使用 SQL 名称 |

**高级特性：**

- SQL 结果包含 `_sheet_name` 列时，系统自动按该列值分 Sheet 生成 Excel
- 支持 `${startTime}`、`${endTime}` 等时间参数，可通过默认时间快捷填充
- 参数值使用 JSON 对象格式，例如：`{"startTime": "2026-07-01 00:00:00", "endTime": "2026-07-01 23:59:59"}`

### 4.3 SQL 分组

切换到 **SQL 分组** Tab，可以创建和管理 SQL 分组，便于对大量 SQL 进行分类管理。分组在任务配置时可用于快速筛选 SQL。

## 5. 网页爬取

网页爬取模块支持从 Web 页面采集数据并生成报表。

![网页爬取列表](images/04-task-crawl.png)

### 5.1 列表页面

- 支持按爬取名称、爬取编码搜索
- 表格展示爬取名称、编码、请求 URL、方法、模板、输出格式、状态等信息
- 操作列支持 **编辑** 和 **删除**

### 5.2 新建/编辑爬取配置

点击 **新增爬取** 按钮或列表中的 **编辑** 链接，打开爬取配置对话框。对话框采用多 Tab 页设计。

![爬取新建对话框](images/04a-task-crawl-create.png)

**Tab 页说明：**

| Tab | 配置内容 |
|-----|---------|
| **基础信息** | 爬取名称、编码、请求 URL、请求方法、Content-Type、请求头、URL 参数、请求 Body、Cookie |
| **认证** | HTTP Basic 认证、Bearer Token 等认证方式配置 |
| **SSH 配置** | SSH 隧道配置，支持跳板机访问内网资源 |
| **渲染与选择器** | 页面渲染方式（静态/动态）、CSS/XPath/正则选择器配置 |
| **分页与媒体** | 分页爬取配置、媒体文件下载设置 |
| **输出与图表** | 输出格式、图表类型、图表样式配置 |

**关键配置说明：**

- **请求 URL**：要爬取的目标页面地址（必填）
- **请求方法**：GET / POST
- **请求头 Headers**：JSON 格式，如 `{"X-Api-Key": "xxx"}`
- **URL 参数**：JSON 格式，如 `{"page": "1"}`
- **请求 Body**：支持 `${变量}` 占位符
- **Cookie**：JSON 格式，保存时自动加密
- **代理**：支持 HTTP 代理配置

## 6. 任务管理

任务管理模块用于创建和管理定时调度任务。

![任务管理列表](images/05-task.png)

### 6.1 列表页面

- 支持按任务名称、任务编码搜索
- 表格展示任务名称、编码、排序、应用菜单、触发类型、任务类型、触发配置、状态等信息
- 操作列支持 **编辑**、**立即执行**、**日志**、**删除**
- **同步菜单** 按钮用于将任务同步到企业微信应用菜单

### 6.2 新建任务

点击 **新增任务** 按钮，打开任务配置对话框。

![新建任务对话框](images/05a-task-create.png)

**配置项说明：**

| 字段 | 说明 |
|------|------|
| **任务名称** | 任务的显示名称（必填） |
| **任务编码** | 唯一标识编码（必填） |
| **触发类型** | CRON（定时触发）或 单次（执行一次） |
| **触发配置** | CRON 表达式，如 `0 0 9 * * ?` 表示每天 9:00 执行 |
| **任务类型** | SQL（执行 SQL 查询）或 网页爬取 |
| **状态** | 启用 / 禁用 |
| **排序** | 任务排序值，数字越小越靠前 |
| **应用菜单** | 是否加入企业微信应用菜单 |
| **选择 SQL** | 选择该任务要执行的 SQL（支持按分组或名称搜索） |
| **描述** | 任务描述（可选） |

**CRON 表达式预览：** 输入 CRON 表达式后，点击 **预览** 按钮可查看接下来 5 次的执行时间。

### 6.3 任务操作

| 操作 | 说明 |
|------|------|
| **立即执行** | 手动触发任务执行，不影响定时调度 |
| **日志** | 查看该任务的执行历史记录 |
| **启用/禁用** | 切换任务状态，禁用后定时调度不再触发 |
| **删除** | 删除任务（不可恢复） |

## 7. 任务日志

任务日志模块记录所有任务的执行历史。

![任务日志](images/06-task-log.png)

## 9. 数据源管理

数据源管理模块包含**数据源**、**同步日志**和**自定义 prompt** 三个子模块。

### 9.1 数据源

数据源是 SQL 查询的数据库连接配置。

![数据源列表](images/09-datasource.png)

**列表功能：**
- 支持按数据源名称搜索
- 表格展示名称、类型、主机、端口、数据库、用户名、状态等信息
- 操作列支持 **编辑**、**测试**、**同步**、**记录**、**删除**

**新建/编辑数据源：**

![数据源新建](images/09a-datasource-create.png)

| 字段 | 说明 |
|------|------|
| **数据源名称** | 数据源的显示名称（必填） |
| **数据库类型** | MySQL（必填） |
| **状态** | 启用 / 禁用 |
| **主机** | 数据库服务器地址（必填） |

| **数据库名** | 目标数据库名称（必填） |

**SSH 隧道配置（高级）：**

| 字段 | 说明 |
|------|------|

| **SSH 端口** | SSH 端口号，默认 22 |

| **私钥密码** | 私钥的保护密码（可选） |

**操作说明：**
- **测试**：验证数据源连接是否正常
- **同步**：同步数据库表结构，生成数据字典文档（供 AI 使用）
- **记录**：查看该数据源的同步历史记录

### 9.2 同步日志

记录数据源表结构同步的历史。

![同步日志](images/10-datasource-sync-log.png)

- 支持按数据源筛选
- 表格展示数据源、状态、表数量、耗时、开始时间、结束时间、结果/文档等信息
- 点击 **查看文档** 可以查看该次同步生成的数据字典文档

### 9.3 自定义 prompt

为每个数据源配置自定义的 AI prompt，用于提升 AI 生成 SQL 的准确性。

![自定义 prompt](images/11-datasource-prompt.png)

**作用说明：** 自定义 prompt 会在 AI 生成 SQL 时，与该数据源同步得到的数据字典（表结构文档）一并注入模型，用于固化业务口径、固定过滤条件、表/字段偏好与时间口径，从而生成更精确的 SQL。

- 列表展示所有数据源及其 prompt 配置状态
- 点击 **编辑 prompt** 为指定数据源配置自定义 prompt

## 12. AI 助手

AI 助手模块提供自然语言交互式的数据分析能力。

### 12.1 AI 对话

![AI 对话](images/14-ai-chat.png)

**功能说明：**

- **AI 对话** 模式：与 AI 进行自然语言对话，AI 可以理解业务问题并自动生成 SQL 查询
- **智能配置** 模式：切换不同的 AI 模型配置
- 在下方输入框中输入问题，如"查询上个月销售额排名前 10 的门店"
- AI 会自动分析数据源结构，生成对应的 SQL 并返回查询结果

**使用场景：**

| 场景 | 示例 |
|------|------|
| **数据查询** | "查询上周各城市的订单量" |
| **数据分析** | "分析一下最近 3 个月用户增长趋势" |
| **报表生成** | "生成一份本月销售汇总报表" |
| **图表生成** | "用柱状图展示各地区收入对比" |

## 14. 系统管理

系统管理模块包含**用户管理**和**角色管理**两个子模块。

### 14.1 用户管理

![用户管理](images/17-system-user.png)

**功能说明：**

- 支持按用户名搜索
- 表格展示用户名、昵称、邮箱、手机号、状态、创建时间等信息
- 操作列支持 **编辑** 和 **删除**

**新建用户：** 点击 **新增用户** 按钮，填写用户名、密码、昵称、邮箱等信息，并分配角色。

**编辑用户：** 可以修改用户的基本信息、重置密码、分配角色、启用/禁用账号。

### 14.2 角色管理

![角色管理](images/18-system-role.png)

**内置角色：**

| 角色编码 | 角色名称 | 说明 |
|---------|---------|------|
| **ADMIN** | 系统管理员 | 拥有所有权限，可管理系统的所有功能 |
| **OPERATOR** | 运维人员 | 可管理任务、SQL、数据源等日常运维功能 |
| **VIEWER** | 只读用户 | 只能查看数据，无法进行修改操作 |

**权限说明：** 系统采用 `<资源>:<操作>` 的权限编码模式，例如：

| 权限编码 | 说明 |
|---------|------|
| `task:view` | 查看任务 |
| `task:edit` | 编辑任务 |
| `task:trigger` | 手动触发任务 |
| `datasource:view` | 查看数据源 |
| `datasource:edit` | 编辑数据源 |
| `system:user` | 用户管理 |
| `system:role` | 角色管理 |
| `auditLog:view` | 查看审计日志 |

**自定义角色：** 点击 **新增角色** 按钮，创建自定义角色并分配所需的权限。

## 附录

### A. 常见问题

**Q: 忘记密码怎么办？**
A: 联系系统管理员在用户管理中重置密码。

**Q: 任务执行失败如何排查？**
A: 在"任务日志"页面查看失败的日志记录，点击错误信息查看具体原因。

**Q: 如何设置任务之间的依赖关系？**
A: 在任务编辑对话框中配置依赖链，指定前置任务。

**Q: 报表文件存储在哪里？**
A: 默认存储在服务器本地，可在"存储配置"中配置阿里云 OSS、AWS S3 或 WebDAV 作为远程存储。

**Q: AI 助手无法生成 SQL 怎么办？**
A: 请确保已在"数据源管理"中执行了表结构同步，并在"AI 配置"中配置了可用的 AI 模型。

### C. 外部 API 触发

系统支持通过 API 从外部触发任务执行：

```bash
curl -X POST http://<server>:1236/api/public/tasks/{taskId}/trigger \
  -H "X-API-KEY: <your-api-key>"
```
